# RK Developers — Premium Real Estate Website

Static responsive website for RK Developers.

## Included
- Premium black / gold visual system
- Responsive navigation and mobile menu
- Animated hero section
- Scroll reveal animations
- Six selected-work project cards
- Click-to-open project detail modal
- Project-specific images, stats, overview and specifications
- Services, values, leadership, location and enquiry sections
- WhatsApp-ready contact area can be added later
- Email enquiry form using mailto
- Supplied RK Developers logo and project brochure images

## Run locally
Open `index.html` in a browser, or use a simple local server.

## Edit projects
Project data is in `script.js` in the `projects` array.
